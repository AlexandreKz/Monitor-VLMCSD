# General Settings

## What it is

The look of the panel and the path to the vlmcsd log.

## Theme

16 themes: Dark, Light, Gray, Ash & Flame, Night Elf, Corporate, Business Classic, Silver Standard, Dark Quartz, Cabernet Sauvignon, Spring, Winter, Summer, Autumn, Poker, Corporate Blue.

Below the list is the “Theme Preview” block (a button, success and error messages, sample text). The theme is applied with the “Apply Theme” button and is saved for both the panel and the main page.

## Language

“Русский” or “English”. Applied with the “Save Language” button. Texts of background tasks and notifications also use the selected language.

## Log File

- **Log file path** — the path to the vlmcsd log on the server (by default `/var/log/vlmcsd.log`, or a `vlmcsd.log` link in the web folder).
- **Status** — “File found” or an error message (no file, no read permission).
- The “Save Path” button. A path change is written to the “Event log” and can trigger the “KMS log path changed” notification.
