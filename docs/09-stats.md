# Статистика и отчёты

## Что это

Сводка по логу vlmcsd: общие цифры, графики активности и готовые отчёты.

## Логика работы

1. Панель считает данные из лога.
2. На вкладке «Статистика» видны итоги, топы и графики.
3. На вкладке «Отчёты» выберите отчёт, задайте параметр и нажмите «Показать».
4. Результат можно выгрузить в XLSX или PDF.

## Вкладка «Статистика»

- **Карточки:** «Всего устройств», «Всего групп», «Всего запросов».
- **По группам** — сколько устройств в каждой группе.
- **Топ IP адресов** и **Топ стран** — самые частые источники запросов. Страна определяется по IP и берётся из кэша геолокации (его можно очистить и обновить в «Инструменты → Управление кэшем»). Если данных нет, показывается «Нет данных об IP» или «Нет данных о странах».
- **Общая активность** — график запросов по периодам. Переключатель «Дни», «Недели», «Месяцы».
- **По устройству** — тот же график для выбранного устройства.

## Вкладка «Отчёты»

Выберите «Отчёт», при необходимости укажите параметр и нажмите «Показать». Под таблицей кнопки «XLSX» и «PDF» для выгрузки результата.

| Отчёт | Что показывает | Параметр |
|---|---|---|
| IP-адреса устройства | Все адреса, с которых устройство обращалось к серверу | Имя устройства (подсказки берутся из лога) |
| Устройства на IP | Все устройства, обращавшиеся с выбранного адреса | IP-адрес |
| Устройства с несколькими IP | Устройства, менявшие адрес: смена сети, VPN, ноутбук в разных офисах | — |
| IP с несколькими устройствами | Адреса, за которыми несколько устройств: NAT, офис или подозрительный источник | — |
| Топ устройств по запросам | 50 самых активных устройств | — |
| Давно не появлявшиеся устройства | Устройства, которых нет в логе дольше выбранного срока | Срок |
| Новые устройства | Впервые появившиеся в логе за выбранный срок | Срок |
| Продукты | Сколько уникальных устройств и запросов на каждый продукт | — |
| По стране | IP-адреса выбранной страны и устройства с них | Страна (из кэша геолокации) |

Если в логе ничего не найдено, показывается «В логе ничего не найдено». Все отчёты доступны и через [«API»](08-api.md).
