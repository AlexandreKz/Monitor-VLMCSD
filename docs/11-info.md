# Информация

## Что это

Справка о сервере и проекте: структура файлов, файлы данных и проверка состояния компонентов.

## Сервер

ОС, ядро, хост, IP сервера, веб-сервер, версия PHP, uptime, время сервера.

## Структура проекта

Дерево файлов проекта: имя, тип, размер, дата. Вверху строка «Обновлено в …: файлов N, изменилось N» и кнопка обновления. Цветные подсказки показывают готовность функций: 95–100% стабильно, 85–94% работает, ниже 85% в разработке.

## Файлы данных

Каталог данных и список служебных файлов: имя, назначение, полный путь, статус «не создан» или размер. Среди них:

- `vlmcconf_config.json` — настройки панели;
- `users.json` — учётные записи и права;
- `audit.log` — журнал событий;
- `notify.json`, `notify.key`, `notify_history.jsonl` — каналы и правила уведомлений, ключ шифрования секретов, история отправок;
- `update_state.json`, `github_token.json`, `update.lock` — состояние обновлений, токен GitHub (зашифрован), блокировка;
- `config_changes.log`, `users_changes.log` — трассировка изменений;
- `backups/` — резервные копии настроек и пользователей.

Ключ `notify.key` нужен для расшифровки секретов: не теряйте его при переносе данных.

### Перенос, откат и резервные копии

- **Перенос.** При первом открытии панели после создания папки данных файлы `users.json` и `vlmcconf_config.json` копируются, проверяются и удаляются из старого места (`vlmcconf/`). Копия «до переноса» остаётся в подпапке `backups/` новой папки.
- **Обновление и откат.** Обновление панели данные не затрагивает: они лежат вне папки проекта. Не возвращайтесь на версию панели, которая не знает о новой папке: она не найдёт `users.json` в старом месте и создаст нового пользователя `root`. Для резервной копии сохраняйте папку данных целиком.
- **Копии перед изменениями.** Перед каждым изменением настроек и списка пользователей панель сохраняет копию в `backups/config/` и `backups/users/` (последние 50 каждого). Если файл повреждён, панель восстановит его из последней копии, а повреждённый сохранит рядом (`*.broken`). Каждое сохранение записывается в `config_changes.log` и `users_changes.log` (метка SHRINK означает уменьшение числа записей).
- Если `users.json` пропал, но копии есть, пользователи восстанавливаются из копии. Чтобы осознанно сбросить пароль `root`, удалите `users.json` и папку `backups/users`.
- Каталог `vlmcconf/cache` пока остаётся на прежнем месте.
