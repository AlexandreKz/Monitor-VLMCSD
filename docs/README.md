## Как устроена панель

- Главная страница `/vlmc.php` показывает лог KMS-сервера и открыта всем (IP-адреса можно скрыть от неавторизованных, см. «Безопасность»).
- Панель управления `/vlmcconf/` открывается после входа. Слева меню разделов, справа выбранный раздел. Какие пункты меню видны, зависит от прав пользователя.
- Первый вход: логин `root`, пароль `root`. Панель сразу потребует сменить пароль.
- Данные панели (настройки, пользователи, журналы, ключи) лежат в папке данных вне веб-папки: по умолчанию `/var/lib/vlmc-monitor/`.
- Языки интерфейса: русский и английский. Темы оформления: 16 вариантов.
