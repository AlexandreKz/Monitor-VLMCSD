# Права пользователей

## Что это

Таблица прав: какое право что открывает в панели.

Права выдаются при добавлении пользователя и меняются кнопкой ✎. Для большинства разделов три уровня: 🚫 нет доступа, 👁️ только просмотр, ✏️ полный доступ. Для белых IP и уведомлений два состояния: ✅ и ❌.

## Таблица прав

| Право | Что открывает |
|---|---|
| Группы: просмотр / редактирование | Раздел «Группы»: список групп; создание, переименование, цвета и значки, удаление |
| Устройства: просмотр / редактирование | Раздел «Устройства»: список и фильтры; добавление, правка, удаление, массовое перемещение |
| Логи: просмотр / редактирование | Журнал событий, «Статистика и отчёты», просмотр лога на главной |
| Пользователи: просмотр / редактирование | Раздел «Безопасность»: таблица пользователей; создание, права, пароли, удаление |
| Информация: просмотр | Раздел «Информация» |
| Инструменты: просмотр / редактирование | Раздел «Инструменты»: просмотр; экспорт, сброс, очистка лога и кэшей, обновление |
| IP Whitelist: управление | Список «Не подозрительные» и добавление адресов с главной страницы |
| Интеграции: просмотр / редактирование | Просмотр интеграций и настроек; изменение настроек AD, синхронизация пользователей, управление Webhook |
| API: просмотр / редактирование | Раздел «API»: документация; управление ключами и настройками |
| Уведомления | Раздел «Уведомления»: просмотр и изменение каналов доставки и правил |

## Полный администратор

Пользователь со всеми правами считается полным администратором. Только он видит раздел «API» и меняет настройку «Скрывать IP-адреса от неавторизованных». Учётная запись `root` создаётся при установке с паролем `root`, и панель требует сменить его при первом входе.

## Права для доменных пользователей

При входе через Active Directory новому пользователю выдаётся шаблон из «Интеграции → Active Directory / LDAP → Права новых пользователей»: «Просмотр: лог и устройства», «Просмотр: лог, устройства, группы, информация» или «Работа: просмотр и изменение устройств и групп». Потом права можно поменять вручную.
