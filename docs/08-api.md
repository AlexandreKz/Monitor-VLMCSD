# API

🔒 Доступ: только полный администратор.

## Что это

REST API только для чтения: данные панели можно получать из Zabbix, Grafana и своих скриптов.

Адрес API: `https://ваш-сервер/vlmcconf/api.php/v1`. Используйте только HTTPS: ключ передаётся открытым текстом.

## Логика работы

1. Включите API на вкладке «Настройки».
2. Создайте ключ на вкладке «Ключи» и сохраните его: он показывается один раз.
3. Передайте ключ в заголовке запроса и получите данные в JSON.
4. Вкладка «Документация» описывает все методы с примерами.

## Вкладка «Ключи»

Таблица ключей: название, ключ (показывается начало), область доступа, разрешённые адреса, срок, последнее использование, статус. Кнопка «Новый ключ» открывает окно:

- **Название** (например, Zabbix, Grafana).
- **Доступ** — области: «Состояние», «Устройства», «Группы», «Лог», «Статистика», «Отчёты», «Безопасность», «Журнал событий».
- **Разрешённые адреса** — IP-адреса и сети (CIDR), с которых можно использовать ключ; пусто — без ограничения.
- **Действует до** — срок действия (календарь).

После создания ключ вида `kms_…` показывается один раз, потом его не восстановить: в панели хранится только хеш. Ключи можно отключать, включать и удалять. Создание, изменение и удаление пишутся в «Журнал событий».

## Вкладка «Настройки»

- **Включить API** — общий выключатель. Применяется сразу.
- **Лимит запросов** — число запросов в минуту на ключ (по умолчанию 60, 0 — без ограничения). При превышении ответ 429 с заголовком `Retry-After`; остаток виден в заголовках `X-RateLimit-*`.
- **Разрешённые источники (CORS)** — по одному адресу в строке или `*`. Нужно только для запросов из браузера, по умолчанию закрыто.

Защита от перебора: 20 неверных ключей в минуту с одного адреса блокируют адрес. Ограничение панели по IP на API не распространяется: у ключей свои списки адресов.

## Как пользоваться

Ключ передаётся в заголовке `Authorization: Bearer kms_…` или `X-API-Key`. Пример:

```text
curl -H "Authorization: Bearer kms_…" https://ваш-сервер/vlmcconf/api.php/v1/status
```

Поддерживаются только запросы GET.

## Вкладка «Документация»

Блок «Поиск и фильтры» (поиск по методам, фильтры по типу метода и по области доступа, кнопка `openapi.json` для Swagger Editor и Postman) и блок «Методы» (описание, пример запроса и ответа с кнопкой копирования).

### Методы (22)

| Область | Методы |
|---|---|
| Состояние | `/v1/status` (версия, состояние лога), `/v1/health` (результат вкладки «Статус», удобно для мониторинга) |
| Устройства | `/v1/devices`, `/v1/devices/{name}`, `/v1/devices/{name}/ips` |
| Группы | `/v1/groups`, `/v1/groups/{name}` |
| Лог | `/v1/log` (фильтры device, since, limit) |
| Статистика | `/v1/stats` |
| Безопасность | `/v1/unknown-devices`, `/v1/whitelist-ips` |
| Журнал событий | `/v1/audit` |
| Отчёты | `/v1/reports/device-ips`, `ip-devices`, `multi-ip-devices`, `shared-ips`, `top-devices`, `inactive-devices`, `new-devices`, `products`, `countries`, `by-country` |

Описание открыто без ключа: `/vlmcconf/api.php/v1/openapi.json`.

## Важно

- Ключ показывается один раз и потом не восстанавливается: сохраните его сразу.
- Используйте API только по HTTPS: ключ передаётся открытым текстом.
- Не выдавайте ключам лишних областей доступа и ограничивайте их по IP.
